# PySide6 Calculator

A simple desktop calculator built with Python, PySide6, and SQLite.

## Features

- Graphical user interface (GUI)
- Addition, subtraction, multiplication, and division
- Decimal and negative number support
- Calculation history saved in SQLite
- Date and time for calculations
- View previous calculations

## Technologies Used

- Python
- PySide6
- SQLite3

## Project Files

- `calculater.py` — Console calculator
- `calculator_gui.py` — Graphical calculator interface
- `database.py` — Database operations and calculation history

## How to Run

1. Install Python 3.
2. Install PySide6 using pip in your Python environment:

   `pip install PySide6`

3. Run the GUI calculator:

   `python calculator_gui.py`
